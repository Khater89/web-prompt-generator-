Project Forge — ملفات الأداة كاملة

لتشغيل الأداة:
1. فكّ ضغط ملف ZIP بالكامل.
2. افتح index.html الموجود في المجلد الرئيسي بالمتصفح.
3. احتفظ بملفات styles.css وengine.js وstudio.js وapp.js بجانبه.

الوظائف:
وصف المشروع، اقتراحات Auto، تخصيص الصفحات والمكوّنات والوظائف والتصميم، معاينة أولية، توليد PRD وبرومبت البناء، النسخ والتنزيل.

الكود:
ملفات الواجهة الرئيسية هي HTML وCSS وJavaScript وتستطيع تعديلها في VS Code.
مجلد source يحتوي الكود الأصلي والاختبارات وسكربت البناء، إضافة إلى كود سيرفر اختياري تم تجهيزه سابقًا.
السيرفر الاختياري غير مفعّل وغير مستخدم في هذه النسخة. لا تحتاج مفتاح API لتشغيل الأداة الحالية.
Auto يقترح باستخدام قواعد وكلمات من الوصف؛ هذه النسخة لا تتصل بنموذج AI.

الحفظ:
لا تحفظ الأداة المشاريع تلقائيًا بعد إغلاقها. نزّل البرومبت وPRD إذا أردت الاحتفاظ بهما.
قد يمنع المتصفح النسخ التلقائي عند فتح ملف محلي؛ عندها استخدم النسخ اليدوي للنص المحدد.
خط Google اختياري؛ يُستخدم خط بديل إذا لم يتوفر الإنترنت.

لتشغيل الكود الأصلي من مجلد source باستخدام Node.js:
node scripts/build-static.mjs
يُنتج مجلد dist. لتقديمه محليًا يمكن استخدام خادم ملفات ثابتة.

للتحقق من الكود الأصلي:
node --test tests/engine.test.cjs tests/studio.test.cjs tests/ui.test.cjs
الاختبارات التفاعلية هنا محاكاة DOM وليست فحصًا بصريًا في متصفح فعلي.
